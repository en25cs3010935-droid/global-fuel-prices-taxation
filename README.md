# Global Fuel Price Analysis Using Tableau

## Project Overview

This project analyzes global fuel prices using Tableau Public. It compares petrol and diesel prices across countries and examines differences in petrol prices between regions.

## Objectives

* Compare average petrol prices across countries.
* Compare average diesel prices across countries.
* Analyze average petrol prices across regions.
* Present the results using visualizations and a Tableau dashboard.

## Tools Used

* Tableau Public
* GitHub

## Dataset

The project uses a global fuel prices dataset containing country, date, region, petrol price, diesel price, LPG price, tax percentage, income level, and subsidy level fields.

## Visualizations

1. Average Petrol Price by Country
2. Average Diesel Price by Country
3. Average Petrol Price by Region

## Dashboard

The three visualizations are combined into a dashboard titled Global Fuel Price Analysis.

## Conclusion

The visualizations provide a simple comparison of fuel prices across countries and regions. The dashboard helps users explore differences in fuel prices using the available dataset.
